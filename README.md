## 🚀 How to Run & Preview

Open `index.html` directly in any modern browser:
```powershell
# In PowerShell:
Start-Process "C:\Users\User\.gemini\antigravity\scratch\deepak-verma-portfolio\index.html"
```
Or start a local live server:
```bash
npx serve C:\Users\User\.gemini\antigravity\scratch\deepak-verma-portfolio
```

## 🛠️ How to Customize Profile Details

All details are clearly organized and formatted in:
- `index.html`: Update your personal bio, project names, and contact emails.
- `script.js`: Update the `circuitRolesData` object (lines ~180-240) to add specific company names, dates, or responsibilities.
- `style.css`: Tweak colors, fonts, and animation speeds.

## 🌐 Free 1-Click Deployment

- **GitHub Pages:** Push to a GitHub repository, go to `Settings` -> `Pages` -> Select `main` branch.
- **Vercel:** Run `npx vercel` inside this folder or import from GitHub.
- **Netlify:** Drag and drop this folder directly into [app.netlify.com/drop](https://app.netlify.com/drop).
